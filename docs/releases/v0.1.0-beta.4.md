Anyu 的第四个预发布版本，加入进程隔离的多环境运行、自定义下载文件夹设置，并修复多环境退出时序与代理设置交互问题。

## 相比 v0.1.0-beta.3 的变化

- **多环境（Profile）隔离**：支持同时并排运行多个独立环境，每个环境拥有独立进程、代理核心、数据目录与强调色，可在工具栏和 `设置 → 环境配置` 中新建、切换、并排打开、重命名、导入或删除环境。
- **自定义下载文件夹**：`设置 → 下载` 新增「下载位置」设置，支持更改、打开与恢复默认（按当前环境保存在本地数据库，修改后立即对新下载生效；自定义目录不可用时自动回退至环境默认目录）。
- **退出时序修复**：完善窗口、浮层与 `WebContents` 析构同步，并在 `before-quit` 中等待所有窗口关闭、代理核心停止及多环境注册表同步完成后再关闭数据库与释放进程锁，解决多环境同时开启时的退出报错。
- **代理设置交互修复**：在 `设置 → 代理` 底部「新来源」栏点击添加订阅链接或粘贴内容时，输入框就近在触发按钮位置展开并自动聚焦，不再跳到节点列表顶部。

## 安装包没有签名

系统会在第一次打开时拦截，绕过步骤见 [README 的“下载与安装”](https://github.com/5nix/anyu-browser#下载与安装)：

- **macOS**：在“系统设置 → 隐私与安全性”里点“仍要打开”，或运行 `xattr -dr com.apple.quarantine /Applications/Anyu.app`。
- **Windows**：SmartScreen 提示时点“更多信息 → 仍要运行”。

## 需要知道的

- 这些安装包由 CI 构建，发布前没有在真机上逐个安装验证。Windows 版的功能验收基于此前的一次真机测试（见 `docs/windows-validation-2026-11-13.md`），此后的改动没有在 Windows 上复测。
- 没有自动更新，新版本需要手动下载。
- 已知限制见 [README](https://github.com/5nix/anyu-browser#已知限制)。
