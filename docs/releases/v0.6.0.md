Anyu 0.6.0 合并了环境与外网状态入口，加入诊断日志和工具栏升级提示，并修复嵌入框架内的跳转和若干界面问题。

## 相比 v0.5.0 的变化

- **环境与外网状态合并**：工具栏只保留一个头像按钮，显示环境首字母，底色为环境色，角标表示外网状态。点开后的卡片包含当前环境、放行条件、其他环境的切换，以及“更换节点”“管理环境”。⋯ 菜单里重复的环境入口已删除，`⌘⇧M` 改为打开这张卡片。
- **工具栏统一**：顶部和侧边栏工具栏的悬停和按下样式统一为圆形或药丸形；侧边栏底部不再拥挤。
- **升级提示**：有新版本时，⋯ 按钮上出现一个圆点，打开一次菜单后消失；菜单第一项“更新到 vX”一直保留到更新为止。关闭自动检查后两者都不显示。
- **诊断日志**：`设置 → 高级` 新增“保存日志到硬盘”和“导出日志”。日志平时只保存在内存中，打开开关后才写入硬盘，关闭时删除。
- **嵌入框架跳转**：修复用户在嵌入框架内点击后，整页跳转仍被拦截的问题，例如 Google 账号菜单里的“管理您的 Google 账号”和“添加其他账号”。拦截规则没有放宽。
- **地址栏**：输入、粘贴或从书签和历史打开网址时，加载期间即显示完整地址。
- **网站图标**：首页快捷方式使用已缓存的网站图标（含 `www.` 和 https 对应地址），图标更新后所有窗口的首页同步刷新；补全了图标缓存和下载记录的若干问题。
- **设置**：`环境配置` 中新增“当前环境配置”标题。

## 安装包没有签名

系统会在第一次打开时拦截，绕过步骤见 [README 的“下载与安装”](https://github.com/5nix/anyu-browser#下载与安装)：

- **macOS**：在“系统设置 → 隐私与安全性”里点“仍要打开”，或运行 `xattr -dr com.apple.quarantine /Applications/Anyu.app`。
- **Windows**：SmartScreen 提示时点“更多信息 → 仍要运行”。

## 需要知道的
