Anyu 的第二个预发布版本，主要加入按网站 UA 切换、调整默认浏览器标识策略以及基础广告弹窗/重定向拦截。

## 相比 v0.1.0-beta.1 的变化

- **按网站 UA 切换**：地址栏网站信息菜单支持按站点切换 `默认` / `Chromium` / `Chrome` / `Electron`，切换后提示需要刷新页面（部分网站需清除 Cookie）并提供快捷刷新入口；`设置 → 隐私` 同步提供“网站 UA”管理列表；清除单站 Cookie/数据时保留其 UA 设置。
- **默认标识策略调整**：全局默认暴露真实 `Chromium`（2-brand Client Hints）并移除 `speechSynthesis` 语音列表劫持，减少高风险伪装特征；`https://accounts.google.com` 与 `https://accounts.youtube.com` 内置默认使用 `Electron`，避免触发登录拦截。
- **基础内容与弹窗拦截**：拦截常见第三方广告、popunder 与诱导重定向脚本子资源，并对无近期用户手势触发的弹窗与跨源子框架重定向进行阻断。

## 安装包没有签名

系统会在第一次打开时拦截，绕过步骤见 [README 的“下载与安装”](https://github.com/5nix/anyu-browser#下载与安装)：

- **macOS**：在“系统设置 → 隐私与安全性”里点“仍要打开”，或运行 `xattr -dr com.apple.quarantine /Applications/Anyu.app`。
- **Windows**：SmartScreen 提示时点“更多信息 → 仍要运行”。

## 需要知道的

- 这些安装包由 CI 构建，发布前没有在真机上逐个安装验证。Windows 版的功能验收基于此前的一次真机测试（见 `docs/windows-validation-2026-11-13.md`），此后的改动没有在 Windows 上复测。
- 没有自动更新，新版本需要手动下载。
- 已知限制见 [README](https://github.com/5nix/anyu-browser#已知限制)。
