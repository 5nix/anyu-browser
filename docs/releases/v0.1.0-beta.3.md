Anyu 的第三个预发布版本，加入当地时间显示和标签栏右键菜单，重做状态卡片与代理设置的引导，并修复 Windows 真机测试中发现的问题。

## 相比 v0.1.0-beta.2 的变化

- **当地时间**：盾牌按钮右侧显示 Anyu 向网站呈现的时区的当前时间，点开卡片可看完整日期与时区。`设置 → 个性化`（原“外观”）里可以关闭显示或切换 24 小时制。
- **标签栏右键菜单**：在标签栏空白处右键可新建标签页，或在顶部与侧边标签栏之间切换。
- **状态卡片**：只有结果用颜色表示，不再出现绿色开关旁挂红色警告；未核对或核对失败时，状态旁可直接核对出口；“更换节点”和“打开设置”两个入口同等大小。
- **代理设置**：没有可用节点时，顶部显示添加订阅、从文件导入、粘贴内容的入口；已有节点后，这些入口移到所有来源下方。
- **清除此网站数据**：现在会真正删除该站 Cookie，包括父域上的 Cookie（父域 Cookie 由各子域共用，会一并删除）。
- **快捷键与焦点**：Ctrl+F5 强制刷新；新建空白标签页后焦点直接在地址栏。
- **位置**：未能成功设置配置坐标时，不会授予网页定位权限；未配置位置时直接拒绝，不再询问。
- **指纹一致性**：Worker 中的 `navigator.platform` 与页面一致；`screen.colorDepth` / `pixelDepth` 固定为 24；自检逐项列出字体与 WebGL 仍会露出本机信息。

## 安装包没有签名

系统会在第一次打开时拦截，绕过步骤见 [README 的“下载与安装”](https://github.com/5nix/anyu-browser#下载与安装)：

- **macOS**：在“系统设置 → 隐私与安全性”里点“仍要打开”，或运行 `xattr -dr com.apple.quarantine /Applications/Anyu.app`。
- **Windows**：SmartScreen 提示时点“更多信息 → 仍要运行”。

## 需要知道的

- 这些安装包由 CI 构建，发布前没有在真机上逐个安装验证。Windows 版的功能验收基于此前的一次真机测试（见 `docs/windows-validation-2026-11-13.md`），此后的改动没有在 Windows 上复测。
- 没有自动更新，新版本需要手动下载。
- 已知限制见 [README](https://github.com/5nix/anyu-browser#已知限制)。
