# Anyu

Anyu 是一个桌面浏览器，所有网页请求都必须经过内置代理内核，在任何故障下都不会直连。与普通浏览器挂代理不同，Anyu 只会在确认当前出口国家与你的配置一致后才放行浏览（不一致或内核异常时保持关闭），并向网站呈现与出口匹配的时区、语言和可选位置。

## 下载与安装

前往仓库的 [Releases 页面](https://github.com/5nix/anyu-browser/releases) 下载预发布包。

安装包尚未进行代码签名，因此 macOS 和 Windows 首次打开时都会拦截启动。

### macOS

- **Apple Silicon（M 系列）**：下载 `Anyu-<版本>-mac-arm64.dmg`（或 `Anyu-<版本>-mac-arm64.zip`）
- **Intel Mac**：下载 `Anyu-<版本>-mac-x64.dmg`（或 `Anyu-<版本>-mac-x64.zip`）

安装与首次打开：

1. 打开 `.dmg` 将 `Anyu` 拖入“应用程序”文件夹（或解压 `.zip` 后移入 `/Applications`）。
2. 由于应用未经过公证，首次双击打开会被系统拦截；关闭提示后，打开 **系统设置 → 隐私与安全性**，点击 **仍要打开**。
3. 也可以在终端执行以下命令清除隔离属性后再打开：

```bash
xattr -dr com.apple.quarantine /Applications/Anyu.app
```

### Windows（x64）

- **安装器**：下载 `Anyu-<版本>-win-x64.exe`
- **便携版**：下载 `Anyu-<版本>-win-x64.zip`，解压后运行 `Anyu.exe`

SmartScreen 弹出 **“Windows 已保护你的电脑”** 时，点击 **更多信息** → **仍要运行**。

## 第一次运行

首次启动会进入设置向导，按以下顺序完成：

1. **欢迎**：选择界面语言（中文 / English），点击 **开始**。
2. **连接**：选择代理来源：
   - **订阅链接或节点配置**：填写 Clash 订阅链接点击 **获取节点**（仅在获取时从本机直接访问该链接一次，不经代理），或选择本地 Clash YAML 文件 / 直接粘贴配置内容。
   - **这台电脑上已在运行的代理软件**：选择 `SOCKS5` 或 `HTTP`，填写本机回环地址（如 `127.0.0.1`）与端口（常见 `7890`、`10808`），如有认证可填用户名和密码。
3. **选择节点和出口国家**：若使用订阅或节点配置，先选择一个节点（可点击 **测速**），然后选择预期的 **出口国家或地区**，点击 **核对出口**。
4. **核对出口**：Anyu 检查代理核心、节点或本机端口以及当前出口国家。核对通过并显示 **外网已放行** 后才能进入下一步；若国家不符，可切换节点或改为实际测出的国家。
5. **身份**：根据已核对的出口国家，Anyu 会建议匹配的 **时区**、**网站首选语言**（不会改变 Anyu 自身的界面语言）和 **位置**（拒绝定位请求，或设为实测城市中心附近约 5 公里）。可直接采用、点 **调整** 修改或保留当前设置。
6. **个性化**：设置外观（跟随系统 / 浅色 / 深色）、标签页位置（顶部 / 侧边）、搜索引擎（DuckDuckGo、Google、Bing 或自定义 HTTPS 网址模板），并可导入 HTML 书签，最后点击 **开始浏览**（若修改了时区、语言或位置，会自动重启使其生效）。

之后随时可以在 **设置 → 状态与检查 → 重新开始设置** 中重新运行该向导，原有配置和节点都会保留。

## 连接方式

三种连接方式可在 **设置 → 代理 → 连接方式** 中切换，外网闸门与出口核对在三种方式下都会执行：

| 模式（设置界面名称） | 流量路径 | 适用场景 |
| --- | --- | --- |
| 默认模式（`system`） | 内置内核按系统路由直连你在 Anyu 中选中的节点 | 直接导入 Clash 订阅或文件使用，或宿主 TUN 不改写连接目标（如 Loon）时选择 |
| 备选模式（`independent`，仅 Windows） | 内置内核绑定系统选出的物理网卡出站，绕过本机 TUN 虚拟网卡 | 在 Windows 上同时运行会改写目标的 TUN 客户端（如开启 TLS 嗅探覆盖目标的 FlClash）且默认模式握手失败时选择；找不到可用网卡时保持关闭，不回退系统路由 |
| 高级模式（`external`） | 内置内核把全部流量转给本机已有代理软件的 HTTP/SOCKS5 端口（仅限 `127.0.0.1` / `localhost` / `::1`） | 希望继续使用本机其他代理软件管理节点和协议时选择 |

选择 **高级模式** 时请注意：Anyu 把流量交给你的代理软件后，实际走哪个出口由那个软件自己的分流规则决定。Anyu 无法读取其内部分流规则，只能通过内置核对端点和你在 **监控网址列表** 中追加的 HTTPS trace 地址（最多 10 条）核对出口；列表之外的域名若被该软件直连，Anyu 不会察觉。

## 已知限制

- **预发布状态**：当前为 0.1.0 预发布版本，可能存在不完善之处；安装包无代码签名、无自动更新；未签名的 macOS 包无法使用系统生物识别或钥匙串通行密钥。
- **指纹一致性是部分的**：
  - 在 Web Worker（Dedicated Worker 与 Service Worker）中，当“呈现的平台”设为非本机系统时，`navigator.platform` 仍为真实宿主机系统；字体和 WebGL/GPU 信息也仍为真实机器的值。
  - 屏幕色深（`screen.colorDepth`）、屏幕尺寸、CPU 核数和设备内存不做伪装，反映真实机器。
  - 本地字体访问接口（`queryLocalFonts`）已拒绝，但网页仍可通过测量字体渲染宽度或 `document.fonts` 检测到本机已安装的字体，包括新安装的字体。
  - `window.chrome` 仅包含 Electron 自带字段，与 Google Chrome 不完全相同。
  - 在极端启动时序下，`SharedWorker` 的首批代码可能在调试器覆盖下发前执行。
- **内置 PDF 查看器**：Windows 真机验收中，打开 PDF 时会显示查看器工具栏但正文为空白（尚未修复）。
- **宿主 TUN 嗅探与 Reality 节点**：默认模式下若宿主机开启了带目标覆盖（`override-destination`）的 TLS 嗅探（例如 FlClash），Reality 节点连接可能失败；可在 Windows 上改用备选模式，或在宿主代理客户端中把节点 IP 加入 `sniffer.skip-dst-address` 例外。
- **订阅与出口核对**：订阅仅支持 Clash YAML 的 `proxies:` 列表（不解析分享链接或 `proxy-providers`）；出口核对依赖内置 trace 端点（及监控网址列表），不可达时外网保持关闭；节点使用域名而非 IP 时，内核在建立隧道前会通过 `1.1.1.1` / `https://1.1.1.1/dns-query` 解析该域名。
- **会话与配置**：所有标签页共享同一个浏览器会话（尚无多容器隔离）；Cookie 依赖系统钥匙串或 DPAPI 加密，跨操作系统拷贝配置文件夹时登录状态可能失效；不支持浏览器扩展与账号同步；更改时区、语言、地理坐标、平台或通知开关后需要重启 Anyu 才会生效。
