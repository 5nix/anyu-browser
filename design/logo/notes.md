# Anyu · 标志定稿

产品名：**Anyu（安隅）**。公开项目名：`anyu-browser`。

标志采用实檐与圆点的黑白构图；字标使用几何线条绘制，不依赖字体。

- `anyu-icon.svg`：标准应用图标，1024 × 1024 画板。
- `anyu-icon-small.svg`：小尺寸应用图标，屋檐加厚、圆点放大。
- `anyu-mark.svg` / `anyu-mark-small.svg`：标准和小尺寸单色标志，使用 `currentColor`。
- `anyu-mark-white.svg`：深色背景使用的白色标志。
- `anyu-lockup.svg` / `anyu-lockup-white.svg`：浅色和深色背景使用的标志与字标组合。
- `anyu-preview.html`：本地静态预览，无外部依赖。

全部 SVG 为纯矢量，不含位图、滤镜、渐变或文字节点。标准版用于较大尺寸，小尺寸版用于 16 / 32px 图标。
