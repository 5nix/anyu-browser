# Exit verification lifecycle at 827cfb0

The gate opens only when the core is up, a node exists, a required country is set, the switch is not paused, and the latest check has succeeded. Runtime rules reject browser traffic while closed; the probe inbound always goes through the selected proxy group. A generation increments on core up/down, node changes, country changes, pause/resume and recheck. Checks start when these facts allow it, and every five minutes while open. A result from an older generation is ignored by the gate reducer.

Import extracts nodes, invalidates the check, replaces the file, reloads the core and invalidates again. Selection invalidates, switches the group, drops browser and core connections, then saves the selection. When a previously open gate closes, dispatch reloads closed rules and drops browser and core connections. Core exit schedules invalidation and a restart; an explicit restart pauses first. Starting the core invalidates again. Operations are serialized, but probes run asynchronously: old results can arrive after a change and are rejected by the reducer's generation check.

The node name is read from the controller before the trace request. The trace uses a shared, cache-disabled Chromium probe session, also used by proxied subscription fetches. Disabling the HTTP cache does not prevent connection reuse, and closing browser/core connections does not close the probe session's connection pool. A request after an import, selection or restart can therefore reuse a connection made through the previous node. Its current-generation successful result may open the gate even though it was not measured through the current node. This is a gate safety issue, not just a label issue.

The nodes UI gets country labels from Gatekeeper's in-memory map, keyed by the name read before the request. The probe writes that map before its result goes through the generation check, so a stale in-flight probe can also write a wrong label; labels survive replacement of nodes with the same names. The reported observation is consistent with these paths, though it does not identify which one occurred.
